pii-protector

pii-protector
v2.2.5 · PyPI

Production-grade PII detection using a sequential multi-model ensemble. Over 90% of text is resolved by the regex layer alone in under 3ms; heavier NER models are only invoked when the cheaper layers can't decide. Install scales from regex-only with zero dependencies up to the full transformer ensemble with GPU support.

50+PII types
4detection layers
<3msfast path
$ pip install pii-protector from pii_protector import Protector result = Protector().scan("Aadhaar 1234 5678 9012") # [{'type': 'AADHAAR', 'score': 0.99}]

Layer 1 regex (~0.3–3ms) → Layer 2 Presidio + spaCy NER (~5ms) → Layer 3 NER transformer (~20ms) → Layer 4 structured PII model (~15ms). Each layer decides whether the next is needed.
