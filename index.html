Open Source · Personal Project

pii-protector

Production-grade PII detection using a sequential multi-model ensemble. Over 90% of text is resolved on the cheapest layer — the expensive models only run when they need to.

pii-protector v2.2.5 · PyPI

Layered escalation keeps the fast path fast: cheap regex resolves the large majority of real traffic, and the transformer NER only fires when the cheaper layers aren’t confident. Covers 50+ types including SSN, credit cards, Aadhaar, PAN, GSTIN, and API secrets.

Sequential escalation ladder
1Regex patterns — structured IDs, cards, secrets~0.3–3 ms
2Presidio + spaCy NER — contextual entities~5 ms
3Transformer NER — low-confidence fallback~20 ms
4Ensemble reconcile — merge, score & dedupe spansmerge
